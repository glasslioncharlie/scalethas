# Scale'thas

## 1.0.1

- Fixed errors ("execution tainted by 'Scalethas'") from Blizzard's unit frames, for example when toggling "Use Larger Frame" in Edit Mode.
- Changing the scale now asks for a UI reload. Cancel puts the old scale back.

## 1.0.0

- Promoted to the live WoW Forever client. The Midnight client is no longer officially supported.

## 0.1.0

- First release: set your UI scale anywhere from 0.30 to 1.15 with a slider, a number box, or a one-click pixel-perfect button.
- `/uiscale`, `/scalethas` or `/st` opens the settings. Add a number, `pixel` or `reset` to use it straight from chat.
